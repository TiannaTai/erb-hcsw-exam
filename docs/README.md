# GitHub Pages

This docs/ folder contains a live client-side generator for the nursing question bank. To publish on GitHub Pages:
1. Go to your repository Settings -> Pages.
2. Set Source: "Deploy from a branch" -> select `main` and `/docs` folder.
3. Save and wait 1–3 minutes; your site will be available at https://<your-username>.github.io/erb-hcsw-exam/

The page generates 1k/2k/5k questions in the browser instantly and supports JSONL/CSV download.
