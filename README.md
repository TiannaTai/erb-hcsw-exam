# Nursing Question Bank

This repository contains a nursing question bank with bilingual (Chinese/English) learning content, plus a browser page for quick viewing.

## Files
- `nursing_questions_Q0101-Q1000.jsonl` is generated by `generate_questions.py`.
- `index.html` provides a quick browser view for inspecting the bank.
- `REPORT.md` summarizes the uploaded question bank.

## Generate the full bank

Run:

```bash
python3 generate_questions.py
```

This creates a JSONL file with 900 new questions in addition to the existing Q0101–Q0250 content, for a total of Q0101–Q1000.

## Why this approach

- avoids duplicate question stems by rotating module/topic combinations
- keeps difficulty distribution balanced
- uses module-based outlines for broad coverage
- supports continuous regeneration for more questions whenever needed
