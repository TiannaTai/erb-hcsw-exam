# Final Project Summary

Repository: TiannaTai/erb-hcsw-exam

## Scope
This repository now includes a large bilingual nursing question bank generator, along with export and browsing utility files.

## Outputs
- JSONL question bank
- CSV export
- one JSON per question under `questions/`
- browser-based viewer

## Use
1. Run `python3 generate_questions.py`
2. Run `python3 export_csv.py`
3. Open `index.html` to review question sets

## Quality note
Use professional review before any high-stakes clinical or formal exam application.
